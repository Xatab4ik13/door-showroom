# План правок по видео

Разобьём на 7 независимых задач — будем делать поэтапно, по одной за раз.

---

## 1. Поставщик у вручную добавленных товаров
**Проблема:** в форме «Добавить/Редактировать товар» нельзя выбрать поставщика — все ручные товары идут как `manual`, и по ним нет фильтра/поиска в админке.

**Что сделать:**
- Добавить в форму товара селект «Поставщик» (список из таблицы `suppliers` + опция «Ручной»).
- Сохранять `supplier_id` / `source` при создании и редактировании.
- В списке товаров админки добавить колонку и фильтр по поставщику.

---

## 2. Дубли производителей в фильтрах
**Проблема:** «Двери Регионов» отображается двумя разными значениями (вероятно: пробелы / регистр / кириллица «е/ё»).

**Что сделать:**
- Нормализовать `manufacturer` при записи (trim, схлопывание пробелов, единый регистр для сравнения).
- Разовая миграция: схлопнуть существующие дубли в одно каноническое значение.
- В фасетах/фильтрах группировать по нормализованному ключу.

---

## 3. Закрепление товаров (pinned / приоритет в категории)
**Проблема:** ручные товары через 1–2 часа после синхронизации проваливаются вниз. Хочется закреплять «топ» (≈20 шт.) в начале категории/каталога — и в «Все товары», и в каждой категории отдельно (например, «Входные»).

**Что сделать:**
- Поле `pinned_order INT NULL` у products (или отдельная таблица `product_pins (category_id NULLABLE, product_id, sort)` для закрепа per-category + глобально).
- В админке у товара кнопка «Закрепить» + поле «Позиция» (или drag-and-drop списка закреплённых).
- На бэке сортировка: сначала `pinned_order ASC NULLS LAST`, потом обычный порядок.
- Синхронизация поставщиков не сбрасывает `pinned_order`.

---

## 4. Структурированные характеристики при ручном добавлении
**Проблема:** в форме нет блока «Характеристики». То, что пишется в «Материал», вылезает не туда; описание скопировать таблицей нельзя. У синхронизированных товаров блок «Характеристики» есть, у ручных — пустой.

**Что сделать:**
- В форму товара добавить редактор «Характеристики» — динамический список пар `ключ → значение` (Производитель, Вес, Открывание, Толщина, Замки, Класс взломостойкости и т.д.) с возможностью добавить/удалить строку.
- Сохранять в `products.specs` (JSONB), который уже рендерит `ProductSpecs.tsx`.
- Пресет «частых» полей кнопкой «Добавить стандартные» (заполняет шаблон полей пустыми, чтобы быстро заполнить).

---

## 5. Цвет показывается как «Покрытие» на карточке
**Проблема:** введённое в форме «Цвет: антик серебро» на карточке выводится в строке «Покрытие». Нужно: «Цвет: антик серебро», «Производитель: …» и т.д.

**Что сделать:**
- В адаптере (`productAdapter.ts` / `ProductSpecs.tsx`) поправить маппинг: `color` → лейбл «Цвет», `coating` → «Покрытие». Сейчас, видимо, всё валится в одну строку.
- Проверить порядок и подписи всех полей характеристик на карточке.

---

## 6. Возврат «Назад в каталог» сбрасывает страницу пагинации
**Проблема:** со страницы товара по «Назад» кидает на 1-ю страницу каталога вместо той, где пользователь был. Плюс лаги при загрузке.

**Что сделать:**
- Хранить состояние каталога (страница, фильтры, скролл) в URL `?page=3&...` — уже частично есть, проверить что ссылка «Назад в каталог» использует `navigate(-1)` или сохранённый query, а не голый `/catalog`.
- При возврате восстанавливать `scrollY` (sessionStorage по ключу пути).
- Глобальный `ScrollToTop` не должен срабатывать при возврате назад в каталог — добавить исключение для перехода `product → catalog` с историей.

---

## 7. Скрытие глобальной панели/услуги на конкретной карточке товара
**Проблема:** обещано «на карточке товара можно отдельно скрыть/добавить» панель или доп.услугу, но в админке такого UI нет.

**Что сделать:**
- В форме редактирования товара добавить блок «Доп. опции этого товара»:
  - список всех привязанных к категории панелей/услуг с чекбоксом «Скрыть на этом товаре»;
  - список рекомендаций с возможностью переопределить.
- Хранить переопределения в `products.extras_overrides` JSONB (`{ hidden_panels: [...], hidden_services: [...], extra_panels: [...] }`).
- На фронте карточки товара применять оверрайды поверх категории.
