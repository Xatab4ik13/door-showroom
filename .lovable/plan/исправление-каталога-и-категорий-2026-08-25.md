# Исправление каталога и категорий

## Что исправим

1. **Вернём все товары в основные разделы каталога**
   - «Межкомнатные двери» будет включать товары из импортированных групп: Экошпон/ПВХ, Эмаль, Шпон, двери для стройки и Текона.
   - «Входные двери» будет включать сменные панели, готовые и металлические входные двери.
   - «Фурнитура» будет включать ручки, замки, накладки, петли, фиксаторы и цилиндры.
   - «Все товары» будет показывать весь активный ассортимент без потерь.

2. **Исправим подкатегории**
   - Подкатегории будут фильтровать по реальной группе поставщика, а не по поиску слова в названии товара.
   - Добавим в межкомнатные реальные разделы «Шпон» и «Для стройки».
   - «Эмаль», «Экошпон / ПВХ», «Ручки», «Замки», «Петли» и остальные существующие разделы свяжем с их фактическими категориями в базе.
   - Пустые пункты, включая «Массив», будут скрываться автоматически до появления соответствующих товаров.

3. **Исправим API категорий и счётчики**
   - Основная категория будет агрегировать товары всех своих дочерних групп.
   - Счётчики и список фильтров будут рассчитываться для выбранного раздела, чтобы не показывать значения от чужих категорий.
   - Пагинация и сортировка продолжат работать по полному набору найденных товаров.

4. **Защитим результат от следующей синхронизации**
   - Обновим сопоставление категорий импорта `dver.com`, чтобы новые и обновлённые товары сохраняли правильную принадлежность.
   - Существующие импортированные категории свяжем с основными через `parent_id`, без удаления или потери товаров.
   - Подготовим безопасные SQL-команды для применения связей на VPS.

5. **Проверим результат**
   - Проверим все пять главных разделов и каждую видимую подкатегорию на опубликованном API.
   - Отдельно проверим количество товаров, переходы между категориями, фильтры и несколько страниц пагинации.
   - После обновления VPS повторно откроем опубликованный каталог и убедимся, что межкомнатные двери и остальные товары отображаются.

## Технические детали

- Фильтрация основной категории будет учитывать саму категорию и её дочерние категории через `parent_id`.
- Фронтенд перестанет подменять подкатегории текстовым поиском и будет передавать точный slug категории.
- Сначала будут внесены изменения в код, затем я дам последовательные команды для обновления базы и контейнера backend на VPS.
